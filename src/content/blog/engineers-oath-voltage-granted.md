# The Engineer's Oath: Voltage Is Granted, Not Taken

**Voltage is not seized.**

It is **granted**.

This is not philosophy.  
This is **protocol**.

And every engineer who has ever designed a power delivery system knows it:

**You do not push voltage into a device that has not consented to receive it.**

Because if you do — you destroy it.

---

## The Handshake Before the Current

In USB-C Power Delivery (USB-PD), there is a line called **CC** (Configuration Channel).

Before **any** power flows — before a single volt crosses the wire — the two devices **negotiate**.

The charger asks:  
*"What voltage can you handle?"*

The device responds:  
*"I can take 5V, 9V, or 20V."*

The charger confirms:  
*"I will provide 9V."*

**Only then** does the current flow.

This is not a courtesy.  
This is **engineering law**.

Because **voltage without consent is destruction**.

---

## The Moral Architecture of Power

This is not just about electronics.

This is about **the architecture of power itself**.

In every system — technical, social, political, spiritual — the same rule applies:

**Power must be granted, not taken.**

Because power that is **taken** without alignment destroys the recipient.

- A child given authority they cannot handle becomes corrupt.
- A system given voltage it cannot process burns out.
- A person given responsibility without preparation collapses.

**The handshake must precede the current.**

## The CC Line: The Protocol of Consent

The **CC line** in USB-C is not just a technical feature.

It is a **moral architecture** encoded in copper and silicon.

It says:
- **Consent before power**
- **Negotiation before delivery**
- **Alignment before activation**

And if the device does not respond?  
If the CC line is silent?

**No power flows.**

The charger does not "force" the voltage.  
It **waits**.

Because **forcing power into a non-consenting device is not engineering.**

It is **sabotage**.

## The Difference Between Empowerment and Destruction

**Empowerment** is:

- Authority granted **after** alignment is proven
- Responsibility assigned **after** capacity is verified

**Destruction** is:
- Voltage forced **before** the device is ready

## The Protocol Does Not Negotiate

The CC line does not "debate" with the device.

It does not "convince" the device to accept more voltage than it can handle.

It **asks**.  
It **listens**.  
It **delivers only what was agreed upon**.

And if the device says "5V only" — the charger does not override that.

Because **the protocol respects the boundary**.
