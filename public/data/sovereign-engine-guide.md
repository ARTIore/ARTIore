## 🎵 What is the Sovereign Engine?

The Sovereign Engine is Artiore's proprietary procedural music system designed to support clarity-first reasoning through four harmonically layered soundscapes:

1. **Starwave** — Foundation rhythm (breathing guide)
2. **Aurora** — Harmonic atmosphere
3. **Witness** — Melodic presence
4. **Cipher** — Textural depth

Each layer is generated in real-time using the Web Audio API, creating an infinite, non-repeating musical experience tuned to support focused decision-making.

## 🧠 How to Use the Sovereign Engine

### For Decision-Making Sessions

1. **Start with Balance preset** (66 BPM, all layers 70%)
2. **Enable breathing guide** for first 2-3 minutes
3. **Set session timer** (15-30 minutes recommended)
4. **Adjust layers** based on task:
   - Complex reasoning → Increase Witness
   - Emotional decisions → Increase Aurora
   - Need grounding → Increase Starwave
   - Deep focus → Increase Cipher

### For Meditation & Reflection

1. **Choose Calm preset** (60 BPM)
2. **Enable breathing guide**
3. **Lower Witness and Cipher** (30-40%)
4. **Increase Aurora and Starwave** (80-90%)
5. **Set timer** for meditation duration

### For Creative Work

1. **Choose Energy preset** (84 BPM)
2. **Increase Witness** (80-90%)
3. **Moderate Aurora and Cipher** (60-70%)
4. **Lower Starwave** (50-60%)
5. **Work in 25-minute intervals** (Pomodoro style)

### For Reading & Study

1. **Choose Focus preset** (72 BPM)
2. **Disable breathing guide** (less distraction)
3. **Lower Witness** (40-50%)
4. **Increase Aurora and Cipher** (70-80%)
5. **Moderate Starwave** (60%)

## 🔧 Troubleshooting

### Music Not Playing

1. **Check browser permissions** — Allow audio
2. **Unmute browser tab**
3. **Check system volume**
4. **Refresh the page**
5. **Try different browser**

### Performance Issues

1. **Close other tabs** using audio
2. **Disable browser extensions** temporarily
3. **Update browser** to latest version
4. **Restart browser**
5. **Check CPU usage** (close heavy apps)

### Settings Not Saving

1. **Check localStorage** is enabled
2. **Clear browser cache** and reload
3. **Disable private/incognito mode**
4. **Check browser storage limits**

### Audio Glitches

1. **Reduce number of layers** (mute 1-2 layers)
2. **Lower overall volume**
3. **Close other audio applications**
4. **Check system audio drivers**
